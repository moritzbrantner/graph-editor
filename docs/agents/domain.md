# Domain Context

This is a single-context repository.

Agents must read root `CONTEXT.md` before making domain decisions. It defines the Graph Editor language and vocabulary.

There is currently no `docs/adr/` directory in this repository.

The domain is Graph Editor: reusable graph document utilities and React primitives for node graph editors. It specializes Editor Core's host-owned document, selection, operation, adapter, and runtime foundation for editable node graphs.
